# dongjinnam.github.io

[dongjinnam.github.io](https://dongjinnam.github.io/) — 백엔드·클라우드·AI 에이전트 엔지니어링 블로그입니다.

- **Stack**: [AstroPaper](https://github.com/satnaing/astro-paper) (Astro + TypeScript + Tailwind CSS + Pagefind)
- **Deploy**: GitHub Actions (`.github/workflows/deploy.yml`) → GitHub Pages
- **Legacy Archive**: 기존 2020~2022 Jekyll 기록은 `archive/legacy-jekyll` 브랜치에 보존되어 있습니다.

## Local Development

```bash
npm install
npm run dev
npm run build
```
